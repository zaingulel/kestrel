# Pre-approved preparation

This file is part of the `resume` skill: a section number or quoted heading in it names a section of
[its SKILL.md](../SKILL.md).

Read with [pre-approved-phase.md](pre-approved-phase.md) and [card-session.md](card-session.md).

Preparation uses `phase: prepare` and the selection fields only. It plans this exact job without building or publishing,
writes the final plan and descriptor, and returns `Run result: prepared <card>` only once the final plan, descriptor and
accepted review evidence are available. The native Codex app coordinator verifies the job's settled review evidence
and writes the accepted record before accepting `prepared`.
