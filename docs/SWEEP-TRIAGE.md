# Sweep triage

Scheduling and activation belong to the documentation routines row in [.agents/REPOSITORY.md](../.agents/REPOSITORY.md). This manual grants no authority to run, file issues, publish, push or merge a routine.

## Purpose

Triage assesses verified documentation gaps left by a sweep. It does not decide product direction or repair agent instructions through a documentation routine.

## Scope

No triage actions are authorised. Owner activation must first define permitted actions, deduplication, trust boundaries and platform controls, grounded in the canonical Fabraik triage manual and [ISSUE-TRACKER.md](ISSUE-TRACKER.md).

## Stop rule

A requested triage stops and reports that activation is required. It changes no files and publishes nothing.
