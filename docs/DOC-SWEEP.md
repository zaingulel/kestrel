# Documentation sweep

Scheduling and activation belong to the documentation routines row in [.agents/REPOSITORY.md](../.agents/REPOSITORY.md). This manual grants no authority to run, publish, push or merge a routine.

## Purpose

A sweep may explain implemented behaviour, never design product behaviour. Code is the authority for implemented behaviour; glossary meaning requires owner direction.

## Scope

No routine edits are authorised now. The table below defines the maximum scope for a future owner-approved activation, limited to factual corrections in these existing manuals. Activation still requires the owner to approve the trust boundary, platform controls and landing procedure. Keep the canonical Fabraik sweep manual as the grounding for that plan; do not assume its hosting controls exist here.

| May edit | Never edit |
|---|---|
| `README.md`, `docs/README.md` | All other files; product code, shared instructions, configuration, evidence and runtime assets. Never create, delete, rename or move a file. |

## Stop rule

A requested sweep stops and reports that activation is required. It changes no files and publishes nothing.
